# Security and LGPD Baseline

- data minimization by default
- explicit purpose per collected data category
- privacy policy and consent records
- account/data export
- account deletion and media erasure workflow
- configurable retention
- signed media URLs
- encrypted transport
- secrets server-side only
- session revocation
- audit trail for deletion/export/admin access
- no private user videos used for model training without explicit opt-in
- no face recognition of minors by default
- family/minor media receives privacy warning UX where appropriate

This is an engineering baseline, not legal advice; production launch requires Brazilian privacy/legal review.
