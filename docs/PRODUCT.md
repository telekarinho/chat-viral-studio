# Creator Copilot — Product Definition

Temporary product name: **Post.ai**

## Core promise
From “I don’t know what to post” to “today’s content is planned, scripted, captured and ready to publish”.

## Primary user
RodrigoSerra.me is the first design partner and beta user.

## Product wedge
The product is not primarily a video editor. Its wedge is the orchestration layer around a creator’s real day:

routine -> daily capture missions -> AI script -> teleprompter/camera -> take library -> post copy -> memory -> performance learning.

## Editorial model
Default pillar targets:
- 40% motivation/reflection
- 20% real life / man 40+ / maturity
- 15% gym / evolution
- 10% family
- 10% humor
- 5% entrepreneurship

Targets are editable per workspace.

## Daily content model
Two default daily items:
1. Thought of the Day — 5–15s discovery content.
2. Main Video — 45s–2m with narrative logic E -> MAS -> POR ISSO.

## UX principle
The home screen answers one question first: **What should I record now?**

Primary navigation:
- Hoje
- Plano
- Gravar
- Projetos
- Resultados

## MVP definition
The first usable release must support:
- authentication
- creator onboarding
- creator profile and voice settings
- routine and recording windows
- pillars and target percentages
- daily agenda
- weekly planning
- Thought of the Day generation
- Main Video generation
- structured AI script output
- reminders
- teleprompter
- native camera
- local-first recording save
- take library
- task states: done, skip, did not happen, reschedule, use another scene
- post caption generation
- basic history
- creator memory
- duplicate/repetition detection

Explicitly out of MVP:
- CapCut-class timeline
- social publishing automation
- advanced analytics
- billing
- team collaboration
- advanced cover generator
- heavy AI video generation
